# Immutable Baseline v1

This directory preserves the observed results before the final-system improvements.

- `baseline_metrics_v1.json` records the pre-improvement retrieval and evaluation metrics.
- `../../notebooks/baseline_kaggle_rag_v1.ipynb` is the baseline Kaggle workflow.
- `../../legacy/etape6_baseline_custom.py` preserves the original custom Ragas-inspired evaluator.

Do not overwrite these artifacts. The final report will compare this baseline with the improved final system.
