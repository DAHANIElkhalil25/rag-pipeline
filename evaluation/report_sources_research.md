# Sources académiques vérifiées pour le rapport PFA RAG

## Fondements RAG, recherche et évaluation

1. Lewis, P. et al. (2020). *Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks*. NeurIPS 2020. Les auteurs décrivent une architecture combinant mémoire paramétrique et index dense externe pour la génération. URL : https://arxiv.org/abs/2005.11401
2. Reimers, N. et Gurevych, I. (2019). *Sentence-BERT: Sentence Embeddings using Siamese BERT-Networks*. EMNLP 2019. L’article décrit des embeddings de phrases comparables par similarité cosinus pour la recherche sémantique. URL : https://arxiv.org/abs/1908.10084
3. Johnson, J., Douze, M. et Jégou, H. (2017). *Billion-scale similarity search with GPUs*. L’article décrit des méthodes de recherche de voisins proches et des index vectoriels pour la recherche de similarité. URL : https://arxiv.org/abs/1702.08734
4. Es, S., James, J., Espinosa-Anke, L. et Schockaert, S. (2023). *Ragas: Automated Evaluation of Retrieval Augmented Generation*. Les auteurs présentent un cadre d’évaluation des dimensions récupération, fidélité et génération des systèmes RAG. URL : https://arxiv.org/abs/2309.15217

## Documentation technique utilisée

5. Ragas. *Available metrics*. Définition et documentation des métriques Faithfulness, Answer Relevancy, Context Precision, Context Recall et Factual Correctness. URL : https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/
6. Python Software Foundation. *Python Documentation, Version 3*. URL : https://docs.python.org/3/
7. Scikit-learn Developers. *Scikit-learn User Guide*. URL : https://scikit-learn.org/stable/user_guide.html
8. LangChain. *LangChain Documentation*. URL : https://python.langchain.com/docs/
9. Mistral AI. *Mistral 7B*. URL : https://arxiv.org/abs/2310.06825
10. Wang, L. et al. (2022). *Text Embeddings by Weakly-Supervised Contrastive Pre-training (E5)*. URL : https://arxiv.org/abs/2212.03533
11. BAAI. *bge-reranker-v2-m3 model card*. URL : https://huggingface.co/BAAI/bge-reranker-v2-m3

## Sources complémentaires vérifiées pour la révision académique

12. Karpukhin, V. et al. (2020). *Dense Passage Retrieval for Open-Domain Question Answering*. EMNLP 2020. L’article établit le principe des récupérateurs denses bi-encodeurs pour les questions-réponses et compare cette famille de méthodes à BM25. URL : https://arxiv.org/abs/2004.04906
13. Gao, Y. et al. (2023). *Retrieval-Augmented Generation for Large Language Models: A Survey*. La revue organise le domaine autour des dimensions récupération, augmentation et génération, et présente les défis de mise à jour, traçabilité et évaluation. URL : https://arxiv.org/abs/2312.10997
14. Yu, H. et al. (2024). *Evaluation of Retrieval-Augmented Generation: A Survey*. La revue analyse les métriques de récupération et de génération, notamment pertinence, exactitude et fidélité. URL : https://arxiv.org/abs/2405.07437
15. Vaswani, A. et al. (2017). *Attention Is All You Need*. NeurIPS 2017. L’article introduit l’architecture Transformer fondée sur l’attention, base des modèles employés dans le projet. URL : https://arxiv.org/abs/1706.03762
16. Devlin, J. et al. (2018). *BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding*. NAACL 2019. L’article est une référence pour les encodeurs bidirectionnels utilisés dans les embeddings et les cross-encoders. URL : https://arxiv.org/abs/1810.04805
17. Wolf, T. et al. (2019). *Transformers: State-of-the-art Natural Language Processing*. EMNLP 2020. L’article décrit la bibliothèque unifiée de modèles Transformer employée pour charger le modèle génératif. URL : https://arxiv.org/abs/1910.03771
18. Abid, A. et al. (2019). *Gradio: Hassle-Free Sharing and Testing of ML Models in the Wild*. HILL 2019. L’article décrit une bibliothèque Python pour construire rapidement une interface de démonstration et de retour utilisateur. URL : https://arxiv.org/abs/1906.02569
19. Wang, W. et al. (2020). *MiniLM: Deep Self-Attention Distillation for Task-Agnostic Compression of Pre-Trained Transformers*. L’article présente une méthode de distillation pour produire des modèles Transformer plus compacts, dont relève la famille MiniLM. URL : https://arxiv.org/abs/2002.10957
