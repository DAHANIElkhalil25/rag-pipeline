# Official Source Coverage for the Final Question Bank

The 120-question final bank is organized into 40 Python, 40 Scikit-learn, and 40 LangChain questions. Reference answers are concise paraphrases of the cited primary documentation; they are marked as source-grounded drafts until a human reviewer validates them against the exact corpus revision used in Kaggle.

## Python

Coverage includes language glossary concepts, functions and decorators, exception handling, files and paths, modules and packages, iterators and generators, context managers, async programming, object-oriented programming, and standard-library utilities. Primary pages include the Python Glossary and `contextlib` documentation.

## Scikit-learn

Coverage includes estimators and the `fit`/`transform` API, pipelines, cross-validation, data leakage, preprocessing and scaling, encoders, imputation, feature selection, metrics, model selection, hyperparameter search, and reproducibility. Primary pages include Pipeline, Common Pitfalls, Preprocessing, and Model Selection documentation.

## LangChain

Coverage includes the LangChain architecture, models, messages, prompts, tools, agents, retrievers, vector stores, chains/LCEL, document loading, text splitting, memory/state concepts, and tracing/evaluation concepts. Primary pages include the LangChain overview and retriever integrations documentation.
